# Security

Report a suspected vulnerability privately to [security@ehven.com](mailto:security@ehven.com).
Include the package version, affected command or API, runtime and Git versions,
expected and actual behavior, and reproduction steps in a disposable repository.
Redact credentials and private refs. Share a backup only after agreeing on a
secure transfer method.

For suspected unsafe retirement behavior, stop using the affected command and
preserve the verified backup and operation journal. Ordinary defects can be
reported in [GitHub Issues](https://github.com/ehven-consultants-npm-products/ehven-git-release-guardrails/issues).
