# Changelog

## 1.0.0

- Portable guards for retirement planning, remote identity and deployment source checks.
- Read-only local and live preview, verified Git backups, and restoration into a new bare repository.
- Explicit retirement bound to a reviewed live plan ID, with exact ref leases, local compare-and-swap and journal recovery.
- Node and CLI entrypoints with TypeScript declarations and zero npm runtime dependencies.

The package follows [Semantic Versioning](https://semver.org/). Preview and
prerelease artifacts may change before publication. Re-run preview after
upgrading, and preserve the original package version and verified backup until
any open recovery operation has been resolved.
